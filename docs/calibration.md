# CLIP threshold calibration

Generated by `python -m eroll.evaluation.calibrate`; re-running it writes a fresh copy to the repository root. The threshold and the `qwen_fallback` rate are copied into `src/eroll/pages/classify.py` by hand.

The rule: the smallest threshold in 0.00 to 1.00 (step 0.01) at which no page of either class is trusted with the wrong label. A page is trusted when its CLIP margin reaches the threshold and CLIP agrees with box geometry. True labels come from position (pages 1, 2 and the last page are non-voter). The calibration PDFs are checked by SHA-256 to share no file with the ground truth.

- Date of fitting: 2026-10-04
- CLIP model: `openai/clip-vit-base-patch32`
- `MAX_CLASS_ERROR_RATE`: 0.0
- Calibration set: 60 PDFs, 8 constituencies, 1744 pages
- Selected threshold: 0.15

## Text prompts

Voter:

- a scanned page with a grid of thirty bordered boxes of voter details
- a scanned electoral roll page listing voters in three columns of boxes

Non-voter:

- a scanned cover page of an electoral roll with a map and paragraphs of text
- a scanned page with a summary table of elector counts
